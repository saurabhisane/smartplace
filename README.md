# SmartPlace

Cloud-Native College Placement Management Platform.

## Tech Stack

### Frontend
- Flutter
- Riverpod
- Dio
- GoRouter

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Flyway

### Database
- PostgreSQL

### Cloud
- AWS-compatible architecture
- Floci for local AWS emulation

### DevOps
- Docker
- GitHub
- Jenkins
- Kubernetes
- Helm
- Terraform
- Ansible

## Local Development

The project is developed locally on Ubuntu using Docker,
PostgreSQL and Floci before deployment to AWS-compatible
production infrastructure.
